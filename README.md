# Gen AI & Agentic AI - Codebasics Course

This repository contains my learning notes, exercises, and project implementations from the [Gen AI & Agentic AI](https://codebasics.io/courses/gen-ai-agentic-ai) course by **Codebasics**.

## 📚 Course Overview
The course covers the fundamentals and practical implementation of Generative AI (Gen AI) and Agentic AI, with a focus on:
- Understanding Large Language Models (LLMs)
- Building AI applications using Python
- Implementing multi-step reasoning and planning
- Integrating tools, APIs, and external data with AI agents
- Best practices for production-ready AI solutions
